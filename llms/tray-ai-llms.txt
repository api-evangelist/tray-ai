# Tray.ai

> Tray.ai is the enterprise orchestration platform for data and AI. One platform to build AI agents, govern Model Context Protocol (MCP), integrate 700+ enterprise systems, and automate work — under one contract.

## Platform capabilities
- Agent Builder (https://tray.ai/platform/merlin-agent-builder) — No-code AI agent development with knowledge, tools, guardrails, and a composable agent hub.
- Agent Gateway for MCP (https://tray.ai/platform/agent-gateway) — Governed MCP (Model Context Protocol) for the enterprise: managed MCP Servers, 700+ connectors as tools, RBAC, observability.
- Intelligent Integration (https://tray.ai/platform/intelligent-ipaas) — Process automation, data integration, API management, and a library of 700+ connectors.
- iPaaS Governance (https://tray.ai/platform/governance-trust) — Observability, audit trails, SOC 1 & SOC 2 / HIPAA / GDPR compliance, 99.99%+ uptime.
- iPaaS Development (https://tray.ai/platform/ai-development) — Headless + low-code authoring with prompt management, model routing, and versioned, composable building blocks.

- [Platform overview](https://tray.ai/platform/): Five pillars unified under one orchestration platform.

## Glossary

- [Agent Gateway for MCP](https://tray.ai/glossary/agent-gateway/): Tray.ai's governance layer for MCP — deploy managed MCP Servers, expose connectors as governed agent tools, and audit every agent action.
- [Agentic AI](https://tray.ai/glossary/agentic-ai/): AI systems that don't just generate responses but take actions — planning, using tools, calling APIs, and completing multi-step tasks autonomously toward a goal.
- [Agentic Automation](https://tray.ai/glossary/agentic-automation/): Automation that uses AI agents to handle tasks requiring judgment — not just fixed steps, but decisions, tool use, and adaptation based on what the agent finds.
- [AI agent](https://tray.ai/glossary/ai-agent/): An AI system that can reason about a task, use tools to act on it, and learn from feedback — not just generate text.
- [AI Agent Orchestration](https://tray.ai/glossary/ai-agent-orchestration/): How multiple AI agents are coordinated to work as a system: which agent acts, when, on what data, and with what oversight.
- [AI-native](https://tray.ai/glossary/ai-native/): Built with AI as a core architectural concern from day one — not bolted on as a feature after the fact.
- [API management](https://tray.ai/glossary/api-management/): The tools and processes for publishing, securing, monitoring, and versioning APIs — so teams can expose data and services without building custom infrastructure for every integration.
- [Change data capture](https://tray.ai/glossary/change-data-capture/): A data integration technique that tracks and streams changes in a database in real time — inserts, updates, and deletes — rather than re-pulling the full dataset on a schedule.
- [Composable](https://tray.ai/glossary/composable/): An architecture where independent, reusable pieces combine freely — so new capability comes from recombination, not rebuilding.
- [Connector](https://tray.ai/glossary/connector/): A pre-built integration between Tray.ai and a specific application — Salesforce, Slack, Snowflake, 700+ others.
- [Data integration](https://tray.ai/glossary/data-integration/): The practice of moving, normalizing, and synchronizing data between systems — so one application's data is usable in another.
- [Enterprise automation](https://tray.ai/glossary/enterprise-automation/): Using software to execute business processes automatically — at the scale, reliability, and governance that enterprise operations require.
- [ETL](https://tray.ai/glossary/etl/): Extract, Transform, Load — the process of pulling data from source systems, reshaping it, and loading it into a destination like a data warehouse.
- [Governance](https://tray.ai/glossary/governance/): The controls that make automation, integration, and AI agents safe to run in production — audit, access, approvals, compliance.
- [Human-in-the-loop](https://tray.ai/glossary/human-in-the-loop/): A design pattern where a human approval, review, or decision is embedded as a step in an otherwise automated process — keeping people accountable for the decisions that matter.
- [Hyperautomation](https://tray.ai/glossary/hyperautomation/): A Gartner-coined term for the disciplined, enterprise-wide application of automation — combining AI, integration, and process tools to automate everything that can be automated.
- [Intelligent document processing](https://tray.ai/glossary/intelligent-document-processing/): AI-powered extraction of structured data from unstructured documents — invoices, contracts, forms, receipts — so the data can flow directly into downstream systems without manual entry.
- [iPaaS](https://tray.ai/glossary/ipaas/): Integration Platform as a Service — a cloud-hosted platform for building, running, and managing integrations between applications.
- [Low-code](https://tray.ai/glossary/low-code/): A development approach where software is built primarily through visual interfaces and configuration rather than hand-written code — accessible to non-developers, extensible by developers.
- [MCP](https://tray.ai/glossary/mcp/): Model Context Protocol — the emerging standard for how AI agents discover and call tools, data, and services.
- [Merlin Agent Builder](https://tray.ai/glossary/merlin-agent-builder/): Tray.ai's no-code / low-code platform for building AI agents that reason, act, and learn — with guardrails and audit baked in.
- [Orchestration](https://tray.ai/glossary/orchestration/): Coordinating data, integrations, automations, and AI agents as one system — not just moving data between apps.
- [Process automation](https://tray.ai/glossary/process-automation/): Using workflows to execute business processes — onboarding, approvals, order-to-cash, incident response — without human-in-the-loop for routine steps.
- [Task](https://tray.ai/glossary/task/): Tray.ai's unit of workflow execution — a discrete run that handles one trigger through the workflow's logic to completion.
- [Workflow](https://tray.ai/glossary/workflow/): A sequence of steps that runs when a trigger fires — the unit of automation that moves data, calls systems, and orchestrates outcomes.
- [Workflow automation](https://tray.ai/glossary/workflow-automation/): Software that executes a defined sequence of steps automatically — moving data, triggering actions, and routing decisions without manual intervention.
